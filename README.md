# Real Mart Sales Analysis Dashboard

## Project Overview
This project is an interactive Sales Dashboard developed in Microsoft Excel to analyze and visualize sales performance. The dashboard provides insights into sales trends, profit, customer ratings, branch performance, city-wise sales, and payment method distribution.

## Dashboard Features

### Key Performance Indicators (KPIs)
- Total Sales: ₹6,59,272.48
- Total Profit: ₹31,393.93
- Total Orders: 2064
- Average Rating: 7.2

### Interactive Filters
- Product Line
- Branch
- City
- Gender
- Date Timeline

### Dashboard Visualizations
- Monthly Sales Trend
- Total Sales by City
- Sales vs Gross Income Analysis
- Sales Distribution by Payment Method
- Sales by Branch

## Key Insights
- Monitored overall sales and profit performance.
- Analyzed monthly sales trends to identify peak sales periods.
- Compared sales and gross income across different product lines.
- Evaluated sales performance across branches and cities.
- Examined customer payment preferences.
- Tracked customer satisfaction through average ratings.
